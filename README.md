Neon Vice — a GTA 6-style cover maker: turn your photo and a caption into a multi-panel poster cover with a Vice City sunset or neon colour grade, and export it as a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Serve the app locally with `node serve.ts`, then open http://localhost:8080. Photos are read on your own machine and never uploaded; the app works with the network off.
